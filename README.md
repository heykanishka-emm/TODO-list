# To-Do List Web App 📝

This is a simple **To-Do List** web application created as part of my learning journey in web development.

The project was **AI-assisted**, where AI tools were used to generate an initial structure. I then focused on understanding the code, debugging errors, and making small improvements on my own.

## 🔹 Features
- Add tasks to a to-do list
- Mark tasks as completed
- Delete tasks
- Simple and clean user interface
- Runs directly in the browser

## 🔹 Technologies Used
- HTML
- CSS
- JavaScript
- GitHub Pages (for deployment)

## 🔹 What I Learned
- Reading and understanding existing code
- Debugging and fixing errors
- Modifying logic instead of writing everything from scratch
- Basic project structure for a web application
- Using GitHub Pages to deploy a project

## 🔹 Project Status
This project is **still in progress** and was built for learning purposes. More features and improvements may be added in the future.
